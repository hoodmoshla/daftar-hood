# 📔 دفتر هود الذكي

تطبيق ويب عربي كامل لإدارة العمل والمشاريع والحياة اليومية.
جوال أولًا • RTL • يعمل بدون إنترنت • بياناتك على جهازك فقط.

## تشغيل سريع

```bash
python3 -m http.server 8000
# افتح http://localhost:8000/app/index.html
```

## الاختبارات

```bash
sh test/all.sh        # ٢٨٧ اختبارًا للمنطق واللغة والتحمل
```

اختبار الواجهة (٦١ اختبارًا) في المتصفح: `test/ui-test.html`

## ما يعمل فعليًا

- ✅ تسجيل المهام بالكلام (عربي + لهجة يمنية) — يعمل محليًا بدون إنترنت
- ✅ ٣ أقسام + ٢٠ تصنيفًا + إنشاء أقسام مخصصة
- ✅ بطاقة مراجعة قبل الحفظ
- ✅ مؤقت عمل مع حفظ الوقت عبر الجلسات
- ✅ اجتماعات + تصدير تقويم `.ics` مع تنبيه قبل ١٥ دقيقة
- ✅ ١٢ نوع مسودة في «أقدر أساعدك فيها»
- ✅ نسخ احتياطي واستعادة (JSON) + تصدير CSV
- ✅ وضع ليلي/نهاري، بحث، ترشيح

## ما يحتاج إعدادًا

- ⚙️ **Google Calendar المباشر** — يحتاج OAuth Client ID (مجاني)
- 🔔 **إشعارات الخلفية** — غير مُنفَّذة؛ استخدم تقويم هاتفك
- ☁️ **المزامنة السحابية** — غير مُنفَّذة؛ نقل يدوي عبر JSON

التفاصيل في [docs/SETUP-AR.md](docs/SETUP-AR.md).

## قواعد الصدق

- لا اختلاق لأي اسم أو رقم أو تاريخ — الحقول الناقصة تظهر بين `[أقواس]`
- «تم» على مهمة تحصيل = «أكملت المتابعة»، وليس سدادًا
- حالة التقويم صادقة: «في الدفتر فقط» حتى نجاح الربط فعليًا
- **أداة مهام، ليست نظامًا محاسبيًا** — لا تتصل ببيانات العمل
